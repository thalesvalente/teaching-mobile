Checkpoint individual
CONSOLIDARIFMA

Explique sem decorar: quatro perguntas

1. O que significa [id].tsx?

Um segmento variável da rota. O mesmo arquivo atende a IDs diferentes.

2. Quem atualiza o título ao digitar?

onChangeText entrega o texto a setTitulo. A função pede a atualização do estado.

3. Por que só espaços não passam?

trim() retira os espaços das pontas. Só espaços viram texto vazio: tamanho 0.

4. Por que replace após registrar?

Ele troca o formulário pelo detalhe do item novo. Não adiciona outra tela ao histórico.

Confira: cada parte tem uma responsabilidade

1 · Rota dinâmica

[id].tsx reutiliza a mesma tela para IDs diferentes. O item é localizado na coleção.

2 · Campo controlado

value exibe o estado. onChangeText entrega o texto à função de atualização.

Após trim(), só espaços viram texto vazio. O envio é interrompido por return.

4 · Histórico de navegação

replace troca a tela atual. No caminho da aula, voltar do novo detalhe leva à lista.

Como usar esta aula

← → ou Page Up/Down navegam. I: índice; C: código; N: notas do professor; R: reiniciar o slide; F: tela cheia; H: ajuda. Home/End: primeiro/último slide. Esc fecha os painéis.

Os atalhos ficam suspensos enquanto você digita em campos ou usa um painel. Não é necessário instalar nada nem estar conectado para usar as demonstrações.

O que é executado: HTML, CSS e JavaScript locais, com um modelo didático de rotas e de histórico. Não há React Native, React Native Web ou Expo Router executando dentro deste arquivo. A validação é derivada do TypeScript de apoio. A prévia não compila os arquivos TSX, não é um emulador e não substitui testes no projeto Expo real.

Código contém sete arquivos completos de referência por trilha para integrar à base existente. Não é um projeto novo com dependências. Os caminhos usam app/; adapte mantendo a raiz e os layouts que o app já utiliza. Não cole as duas trilhas juntas.

Slides usam canvas fixo de 1280 × 720. Apenas o interior das prévias móveis pode rolar quando necessário, como uma tela do app. Em um telefone, use orientação paisagem; para projeção, prefira tela cheia.

Dados são fictícios, sem API nem persistência. Recarregar reinicia tudo. Reiniciar afeta apenas a demonstração e as respostas do slide atual. O checklist é confirmação manual, não execução automática.

PDF / Imprimir gera páginas estáticas: os controles deixam de funcionar e os estados são preparados para leitura. Ao fechar a impressão, os estados anteriores são restaurados. Use margens zero, plano de fundo ativado e não inclua cabeçalhos/rodapés do navegador.

Código completo de referência

Integre ao app da Aula 5. Preserve componentes, estilos, layouts e package-lock.json. Não execute npm ci no pacote de apoio: ele não é um projeto instalável.
