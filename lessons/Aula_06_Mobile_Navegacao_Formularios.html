Voltar: back, goBack ou canGoBack?

Nesta aula, com Expo Router:

Notas do professor

Conceitos e ajuda

Uma consulta rápida, com as mesmas palavras usadas na aula.

Tela × rota

Tela é a interface. Rota é o endereço usado para abri-la. No exemplo, / abre a lista e /memorias/nova abre o formulário.

ID, pathname e params

ID identifica um registro. pathname informa o modelo da rota; params envia os valores. Em /memorias/[id], o valor m1 ocupa o lugar de [id].

router e push

router é o controle de navegação do Expo Router. push acrescenta uma tela ao histórico: a nova fica no topo e a anterior permanece abaixo.

Pilha e Stack

Stack significa pilha. Pense em cartões: o de cima representa a tela atual. O histórico permite revelar a tela anterior ao retirar o topo. A metáfora descreve o navegador Stack deste exemplo.

back × canGoBack

router.back() pede o retorno. router.canGoBack() apenas verifica se há tela anterior: true é sim; false é não.

E goBack?

Em React Navigation, há navigation.goBack(). Nesta aula de Expo Router, usamos router.back(). Não troque os nomes dos objetos: router.goBack() não é o comando desta aula.

replace

Troca só a tela atual por outra. Depois de cadastrar, o formulário é substituído pelo detalhe novo; a lista abaixo continua. Não é limpar toda a pilha.

return × voltar de tela

return encerra a função JavaScript. Na validação, ele impede que o cadastro continue. Isso não é navegar para outra tela: essa ação cabe ao router.
