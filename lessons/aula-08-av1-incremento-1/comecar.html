Preparar o laboratório

Siga uma etapa por vez. Você não precisa instalar extensão de IA nem fazer login no GitHub.

Ir para:ArquivosExecutarTestarDúvidas comuns

1. Obtenha os arquivos da aula

  1. Tenha o VS Code e o Node.js 22 ou superior instalados.
  2. Abra a branch da Aula 08 no GitHub. Clique em Code → Download ZIP. Não é necessário criar uma conta.
  3. Extraia o ZIP e abra a pasta lessons/aula-08-av1-incremento-1/projeto no VS Code.

Este laboratório é Mobile Web e roda no navegador. Não precisa de Expo, APK ou emulador Android.

2. Abra o aplicativo

No VS Code, escolha Terminal → Novo terminal. O terminal precisa estar na pasta projeto, onde está o arquivo package.json.

Copie e execute uma linha por vez
npm ci
npm run preflight
npm run web

Com o terminal aberto, entre em http://127.0.0.1:8088 no navegador do mesmo computador. Para parar, use Ctrl + C.

Experimente buscar “praça”, selecionar uma categoria e abrir os detalhes. Algumas funções estão incompletas de propósito.

3. Teste sem medo de errar

Mantenha o primeiro terminal aberto. Em outro terminal, ainda na pasta projeto, execute:

Verificar o trabalho atual
npm run nota

Você verá OK ou PENDENTE em cada critério. É normal começar com pendências. A nota local serve para aprender e não é a nota oficial da entrega.

Dúvidas comuns

A página abriu um arquivo com símbolos # e **?

Você abriu o README.md diretamente. Ele é documentação técnica. Volte à página da Aula 08 e navegue pelas instruções HTML.

O terminal diz que “npm” não existe

Instale Node.js 22 ou superior, feche e reabra o terminal e tente novamente. Peça apoio ao professor caso a instalação seja bloqueada.

O comando “npm run web” não abre o app

Confira se o terminal está dentro de projeto, se npm run preflight passou e se a porta 8088 está livre. Abra manualmente http://127.0.0.1:8088.

Não tenho internet

Com os arquivos já baixados, você pode editar e testar o projeto localmente. A avaliação oficial e o recibo exigem que a ficha consiga falar com o servidor do professor.

Quero ver uma tela parecida com celular

No navegador, use as ferramentas do desenvolvedor e escolha a visualização de dispositivo móvel. O aplicativo é Web responsivo; não é necessário Expo.
