Preparar o laboratório

Siga uma etapa por vez. Você não precisa instalar extensão de IA nem fazer login no GitHub.

Versão candidata — avaliação por equipe. Quatro tarefas e registro reflexivo de uso ou não uso de IA aguardam aceite docente para avaliação oficial. Os testes locais continuam formativos.

Ir para:ArquivosExecutarTestarDúvidas comuns

1. Obtenha os arquivos da aula

  1. Tenha VS Code e Node.js 22 ou superior instalados.
  2. Abra a branch da Aula 08 no GitHub. Use Code → Download ZIP, ou a pasta fornecida pelo professor.
  3. Extraia o ZIP e abra lessons/aula-08-av1-incremento-1/projeto no VS Code.

Este laboratório é Mobile Web. Não precisa de Expo, APK ou emulador Android.

2. Abra o aplicativo

Escolha Terminal → Novo terminal. O terminal deve estar na pasta projeto, onde está package.json.

Execute uma linha por vez
npm ci
npm run preflight
npm run web

Mantenha esse terminal aberto e acesse http://127.0.0.1:8088 no mesmo computador. Para parar o servidor, use Ctrl + C.

Experimente buscar “praça”, selecionar uma categoria e abrir os detalhes. Algumas funções estão incompletas de propósito.

3. Teste sem medo de errar

Em outro terminal, ainda na pasta projeto, execute:

Verificar o trabalho atual
npm run nota

Leia OK e PENDENTE em cada critério. É normal começar com pendências. A nota local é uma estimativa coletiva, não registra nada na planilha. Todas as equipes trabalham as quatro tarefas, sem escolher um arquivo por pessoa.

Dúvidas comuns

A página abriu um arquivo com símbolos # e **?

Você abriu o README.md diretamente. Volte à página HTML da Aula 08. As instruções para estudantes não dependem de ler Markdown.

O terminal diz que “npm” não existe

Confira a instalação do Node.js 22 ou superior, reabra o terminal e tente novamente. Peça apoio caso a instalação seja bloqueada.

“npm run web” não abre o app

Confira a pasta projeto, o resultado de npm run preflight e a porta 8088. Abra manualmente http://127.0.0.1:8088.

Não tenho internet

Com os arquivos baixados, edite e teste localmente. A avaliação oficial precisa do servidor homologado. Guardar PDF local não confirma entrega.

Quero ver uma tela parecida com celular

Use a visualização de dispositivo móvel nas ferramentas do navegador. O aplicativo é Web responsivo; não exige Expo.

Meu JSONL antigo foi recusado

Obtenha a versão atual do projeto e gere novamente com npm run entrega. Não edite o JSONL para contornar schema ou hashes.

A composição da equipe mudou

Procure o professor. Não omita, acrescente ou troque nomes em reenvios sem reconciliação docente. Reordenar os mesmos participantes não muda a composição.
