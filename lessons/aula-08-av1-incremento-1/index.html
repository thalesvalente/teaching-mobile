Abrir o passo a passo da M4

Só cinco passos para trabalhar

  1. Abrir a aula e preparar. Confira o guia e execute o preflight.
  2. Programar e explicar. Use o Gemini como tutor quando houver necessidade, faça as alterações e registre o processo verdadeiro.
  3. Testar e ver o resultado. Execute npm run nota. Os testes locais podem ser repetidos sem penalidade.
  4. Gerar o pacote. Execute npm run entrega.
  5. Importar e entregar. Na ficha, selecione entrega-a08.jsonl e clique em Avaliar e enviar após liberação docente. O PDF é gerado automaticamente.

A nota local ajuda você a aprender. A ficha pede novos casos e o servidor calcula o resultado da entrega. Se algo falhar, você poderá guardar um PDF local, sem confirmação de envio.

Gemini como tutor, não como executor

Ao usar IA, peça uma explicação ou uma pista, depois faça a alteração no VS Code e rode os testes você mesmo. Não envie senhas, tokens, arquivos .env ou nomes de colegas. Não usar IA pode ser declarado honestamente no registro reflexivo da candidata.

O que precisamos hoje

VS Code, Node.js 22+ e um navegador atualizado. O Gemini é apoio pelo navegador. O starter é Web responsivo: não exige Expo, APK ou emulador. As trilhas nativas anteriores continuam separadas.

Com os arquivos baixados, edição e testes funcionam sem internet. A nota oficial e o recibo exigem rede, aceite docente da política e homologação do servidor.
