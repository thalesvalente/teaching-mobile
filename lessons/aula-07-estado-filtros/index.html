Conceitos desta aula
Estado
Informação que o componente lembra entre renderizações: busca, categoria escolhida e status de carregamento, por exemplo.
Evento
Algo que acontece na interface, como digitar ou tocar. A função associada ao evento pode pedir uma mudança de estado.
Filtro e recorte
Uma regra escolhe quais registros mostrar. A lista completa não precisa ser apagada nem substituída.
FlatList
Componente de lista do React Native. data recebe itens, renderItem desenha cada registro e keyExtractor fornece sua chave estável.
ID e key
O ID identifica o registro. A key ajuda o React a acompanhar aquele item na lista. Neste exemplo, usamos o ID como key.
Vazio não é erro
Carregamento bem-sucedido pode retornar zero itens. Uma falha significa que a operação não terminou como esperado.
Indicador e unidade
Um número resume alguma característica, mas precisa de contexto. Percentual e quantidade de estudantes não são a mesma unidade.
Escala do gráfico
Define quanto um comprimento representa. Barras comparáveis usam a mesma escala, com rótulo, valor e unidade.
