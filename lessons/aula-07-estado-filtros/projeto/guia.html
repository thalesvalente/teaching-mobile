Dados em movimento: projeto e missões

Quatro missões com 20 critérios valendo 0,5 ponto cada. Nota formativa de 0,0 a 10,0 e progresso visível após cada avaliação. A nota não é lançada no SUAP.

Ficha da equipeAcessar projeto ExpoPortal das aulas

Início: como testar e alterar

  1. Abra o projeto Expo pelo link e baixe a pasta ou atualize o clone da equipe.
  2. Entre em lessons/aula-07-estado-filtros/projeto e execute npm run nota (ou node scripts/avaliar.mjs) para ver a pontuação atual, mesmo sem instalar dependências.
  3. Edite as funções pendentes no arquivo src/missoes.mjs. Não altere a rubrica src/avaliacao.mjs.
  4. Execute npm ci e npm run web para abrir a interface. Reexecute npm run nota e registre a evidência e o commit na ficha.

M1 · Estado da tela — 20 XP / 2,0

Implemente classificarTela. Diferencie carregamento, erro, base vazia, nenhum resultado e conteúdo. Teste “Base vazia”, busca zzzz, “Simular erro” e “Tentar novamente”.

M2 · Busca e filtros — 30 XP / 3,0

Implemente filtrar. Combine texto, categoria e período sem apagar a coleção. Teste PRAÇA, o filtro Lugar e a limpeza, que deve restaurar seis registros.

M3 · Identidade da lista — 20 XP / 2,0

Implemente prepararLista. Use IDs estáveis como chaves, preserve ordem e conteúdo do registro. Inverta a ordem e confira detalhes de dois registros.

M4 · Resumo e barras — 30 XP / 3,0

Implemente resumir. Cartões e barras devem derivar do recorte atual e sempre indicar nome, valor e unidade. Em EDA, valores percentuais usam escala 0–100%; quantidades de estudantes ficam fora dela.

Entregar, mesmo parcialmente

Rode npm run nota, abra entrega/resultado.html e use imprimir/salvar PDF. Registre na ficha da equipe as evidências e os critérios pendentes. Dicas e tentativas não descontam XP.
